Privacy Policy — YouTube True Shuffle Toggle

Last updated: 20 August 2026

Short version

This extension collects nothing, sends nothing anywhere, and has no server.

What data the extension handles

The extension stores one small record per playlist, using Chrome's chrome.storage.local API:

  • whether True Shuffle is currently ON or OFF for that playlist;
  • the shuffled order of video IDs;
  • the position in that order.

This data never leaves your computer. It is not transmitted, synced, uploaded, or shared with anyone, including the developer.

What the extension does NOT do

  • It does not collect personally identifiable information, authentication information, browsing history, location, or any user activity.
  • It does not use analytics, tracking pixels, cookies of its own, or advertising of any kind.
  • It does not load or execute remote code.
  • It does not sell or transfer data to third parties — there is no data to sell or transfer.

Network requests

The extension makes requests only to https://www.youtube.com, the same site you are already on, in order to read the list of videos in the playlist you opened. These are the same requests the YouTube page makes for itself. No request is made to any other domain, and no request carries data about you to the developer.

Permissions

  • storage — to remember the shuffled order per playlist, as described above.
  • Access to https://www.youtube.com/* — required to show the button on the playlist page and to read the playlist contents. The extension runs on no other website.

Changes to your YouTube account

The extension never modifies your playlists, your account, or anything on YouTube's servers. It only decides which video this browser tab opens next.
