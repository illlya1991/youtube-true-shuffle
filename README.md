# YouTube True Shuffle Toggle

Розширення для Chrome, яке додає кнопку **"TRUE"** біля нативної
кнопки перемішування на сторінці плейлиста YouTube.

## Що воно робить

- **Реальне перемішування.** Алгоритм Фішера–Єйтса дає рівномірно
  випадковий порядок без прихованих періодичностей чи повторів, на
  відміну від вбудованого shuffle YouTube.
- **Плейлист не змінюється.** Розширення лише зчитує список відео зі
  сторінки і керує тим, яке відео відкрити наступним у цій вкладці.
  Порядок відео у самому плейлисті на YouTube залишається як був.
- **Перемикач "вкл/викл".** Поки вимкнено — все працює як завжди
  (нативний плеєр, нативна кнопка next). Увімкнув — наступні відео
  йдуть за твоїм перемішаним списком; коли список закінчується, він
  перемішується заново для наступного кола.

## Встановлення (режим розробника)

1. Розпакуй архів у будь-яку папку.
2. Відкрий у Chrome сторінку `chrome://extensions`.
3. Увімкни перемикач **"Режим розробника"** (Developer mode) у верхньому
   правому куті.
4. Натисни **"Завантажити розпаковане"** (Load unpacked) і вибери папку
   з файлами розширення.
5. Відкрий будь-який плейлист на YouTube — біля кнопки shuffle з'явиться
   кнопка "TRUE".

## Як читається плейлист

Панель плейлиста в DOM містить лише ті відео, які YouTube встиг
підвантажити (близько 100), тому перемішування "по сторінці" покривало б
тільки початок довгого плейлиста. Замість цього розширення читає ті самі
дані, що й сам сайт: `ytInitialData` зі сторінки `/playlist` плюс
посторінкові запити до `youtubei/v1/browse` за continuation-токеном. Обидва
запити — same-origin до youtube.com, з cookie користувача (тому працюють і
приватні плейлисти) і **без жодного додаткового дозволу**. Якщо формат даних
колись зміниться, є запасний варіант — старе зчитування з DOM.

## Приватність і дозволи

- Єдиний дозвіл — `storage` (не показує жодного попередження при
  встановленні). Доступ обмежений `https://www.youtube.com/*`.
- Дані нікуди не передаються: жодних серверів, аналітики чи віддаленого
  коду. Перемішаний порядок лежить у `chrome.storage.local` на цьому
  комп'ютері.

## Обмеження, про які варто знати

- У YouTube немає офіційного API для керування порядком відтворення
  плейлиста з розширення, тому скрипт працює через аналіз сторінки
  (DOM). YouTube регулярно оновлює верстку, тож якщо кнопка колись
  перестане з'являтися або перехоплення "next" перестане працювати —
  найімовірніше, змінилися селектори на сторінці, і `content.js`
  потрібно буде підправити під нову розмітку.
- Перехоплюються: клік по кнопці "наступне відео" в плеєрі
  (`.ytp-next-button`), гаряча клавіша Shift+N і закінчення відео.
  Щоб не програти гонку власному автоплею YouTube, перехід
  спрацьовує за 0.4 с до кінця ролика. Якщо клікнути по конкретному
  відео в панелі плейлиста збоку — воно відкриється як завжди, це
  нормальна поведінка.
- **Mix / радіо** (плейлисти з id, що починається на `RD`) генеруються
  YouTube на льоту і не мають скінченного списку, тому там
  перемішується лише те, що вже завантажене в панель.
- Стан (увімкнено/вимкнено, поточний перемішаний порядок) зберігається
  окремо для кожного плейлиста через `chrome.storage.local`, тож він
  переживає перезавантаження сторінки.
